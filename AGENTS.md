# Agentes — Prism

Prism é a camada visual e de escrita de todos os projetos do Axolotl BR: tokens,
primitives e componentes React com uma linguagem só, mais a voz que todo texto
publicado segue.

## Escopo

| Tarefa | Fonte |
| --- | --- |
| UI, componente React, tela, layout de produto | `PRISM.md`, `tokens/`, `src/` |
| Texto publicado, microcopy, doc, anúncio, release | `ESCRITA.md` |

Tarefa de marca, identidade, campanha, mascote ou texto institucional não se resolve
aqui. O kit de marca é privado e fica fora deste repositório.

## Regras

1. Não redeclare `--prism-*`. Não passe `className` ou `style` para componente Prism.
2. Não invente componente fora do manifesto.
3. Não invente asset, dado, número, depoimento ou screenshot.
4. Texto publicado em português brasileiro natural. Sem jargão corporativo.
5. Toda peça escrita passa pelo checklist de `ESCRITA.md`. Texto não pode parecer
   saída de IA.
6. Antes de dizer "pronto", rode o checklist de `PRISM.md`.
